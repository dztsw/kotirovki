# Котировки

Мобильное веб‑приложение (PWA) с графиками курсов валют. Без сборки и зависимостей — просто статические файлы для GitHub Pages.

## Возможности
- **Крипта** (Binance, спот, USDT): цены в списке и график обновляются в реальном времени по WebSocket. Таймфреймы от 1 минуты до недели, вид графика: линия или свечи. Любой тикер Binance можно добавить через поиск.
- **Валюты**: курсы на конец дня (ЕЦБ через Frankfurter, для остальных пар currency-api). Любую пару можно добавить поиском, например `USDKZT`.
- **Акции**: Московская биржа (ISS), бесплатно и с задержкой 15 минут. Любой тикер TQBR можно добавить через поиск.
- **Металлы**: золото, серебро, платина, палладий за тройскую унцию, раз в день.
- **Избранное**: инструменты со всех рынков на одном экране.
- Тёмная и светлая тема, установка на главный экран.

Все источники бесплатные и работают без API‑ключей. Графики построены на [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) (Apache 2.0, лежит в `vendor/`).

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него эти файлы.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на телефон
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Обновление
После изменения файлов поменяйте `VERSION` в `sw.js`, чтобы телефоны быстрее подтянули новую версию.
