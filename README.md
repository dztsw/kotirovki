# Курсы валют

Мобильное веб‑приложение (PWA) с графиками курсов валют. Без сборки и зависимостей — просто статические файлы для GitHub Pages.

## Возможности
- Любая пара из ~45 валют (включая RUB, KZT, BYN, UAH, AED, а также BTC, ETH, USDT, TON, золото)
- Периоды: неделя, 1/3/6 месяцев, год, 5 лет
- Касание графика — курс и изменение на выбранную дату
- Избранные пары с изменением за 7 дней
- Светлая и тёмная тема, установка на главный экран, работа офлайн (последние загруженные данные)

## Источники данных (бесплатно, без API‑ключей)
- [Frankfurter](https://frankfurter.dev) — официальные курсы ЕЦБ, если обе валюты есть у ЕЦБ
- [fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api) — для остальных (RUB, СНГ, крипта); история с марта 2024

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите в него эти файлы.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.

## Установка на телефон
- **iPhone (Safari):** открыть ссылку → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** открыть ссылку → меню ⋮ → «Установить приложение» / «Добавить на главный экран».

## Обновление
После изменения файлов поменяйте `VERSION` в `sw.js`, чтобы телефоны быстрее подтянули новую версию.
